# خطوة — إدارة الادخار والماليات

تطبيق محلي يعمل دون حساب سحابي لإدارة الادخار الشخصي أو العائلي أو الجماعي. أنشئ مشاريع مستقلة لأي هدف، مثل التعليم أو السفر أو المنزل أو الاحتياط، وسجّل الأرقام الفعلية لكل مشروع.

## التشغيل

افتح `index.html` في متصفح حديث. إذا منع المتصفح قاعدة البيانات المحلية عند فتح الملف مباشرة، شغّل خادم ملفات محليًا داخل هذا المجلد ثم افتح عنوانه في المتصفح. لا يحتاج التطبيق إلى خدمة خلفية.

## ما يتضمنه التطبيق

- مشاريع مالية متعددة بحالات نشطة أو متوقفة أو مؤرشفة، مع التبديل والتعديل وإعادة الفتح وإعادة ضبط مشروع واحد أو مسح كل المشاريع بعد تنزيل نسخة احتياطية.
- الأهداف المالية الحالية، خطط شهرية، الإيداعات والسحوبات، التقدم والتوقعات.
- أعضاء مرتبطون بمعرّفات ثابتة؛ تعديل الاسم لا يفصل السجلات التاريخية. يمكن أرشفة العضو وإعادة فتحه مع بقاء مساهماته في التقارير، وضبط معدل ادخاره وحصته المستهدفة وحصته من المصروفات المشتركة كلٌّ على حدة.
- دخل فعلي متغير، مصروفات شخصية أو مشتركة، سجلات مخططة وميزانيات شهرية بمقارنة المخطط بالفعلي.
- رصيد افتتاحي للنقد غير المخصص أو الطوارئ أو هدف الادخار، وتحويلات موثقة بين الصناديق.
- ادخار يدوي أو تلقائي من الفائض الفعلي. التنفيذ التلقائي محدد مرة واحدة للشهر، ولا يتجاوز الفائض أو النقد المتاح؛ ويمكن تعديل الدفعة ككل مع إعادة توزيع المبلغ على الأعضاء وحفظه كتحويل داخلي.
- تسجيل الذهب وأصول أخرى يحددها المستخدم. يمكن تعديل شراء الذهب ومصدر النقد والكمية والرسوم، وعندها يعيد التطبيق احتساب المبيعات المرتبطة والكمية والتكلفة المتبقية. يمكن أيضًا تعديل أو حذف عملية بيع، مع إعادة بناء سجل الأصل والربح أو الخسارة على صافي العائد بعد الرسوم.
- ديون بين الأعضاء أو للمشروع وتتبع مبالغ السداد والمتبقي دون إدخال السداد كدخل جديد.
- تقارير الهدف ومساهمات الأعضاء والفروق عن الحصص المستهدفة، مع تنبيه إذا كانت نسب التوزيع غير مكتملة. أرقام لوحة المعلومات القابلة للنقر تفتح السجلات المالية أو عمليات الادخار المرتبطة بها، وسجل التمويل كامل مع تصفية حسب النوع وترقيم صفحات.
- سجل تدقيق، تراجع آمن عن آخر عملية مدعومة، تصدير CSV، نسخ JSON عادي أو مشفر بكلمة مرور، وواجهة عربية RTL وفرنسية وإنجليزية. يتضمن سجل الادخار البحث والتصفية حسب الهدف والعضو والتاريخ ونوع العملية، والترتيب حسب التاريخ أو المبلغ، مع عرض التفاصيل وترقيم الصفحات.
- تعديل الميزانيات والديون وسجلات السداد وعمليات الرصيد الافتتاحي والتحويل بين الصناديق من السجل. تبقى السجلات التاريخية المرتبطة محفوظة أو يعاد احتسابها ضمن عملية واحدة. يمكن حذف الأصول اليدوية غير المرتبطة بعمليات، بينما تتطلب الأصول ذات سجل شراء أو بيع إزالة الحركات المرتبطة أولًا.

## التخزين والترحيل

يستخدم التطبيق IndexedDB إصدار 3 للسجلات المالية وLocalStorage لإعدادات اللغة والمظهر والمشروع المختار. عند فتح قاعدة بيانات الإصدار 1، يُنشأ مشروع مرحّل وتُربط به الأهداف والعمليات والأعضاء وسجلات التدقيق القديمة دون حذفها أو تغيير معرّفاتها. يبدأ كل مشروع جديد بأرصدة صفرية؛ تُدخل الأرصدة السابقة صراحةً من شاشة الدخل والمصروفات.

البيانات مرتبطة بأصل التطبيق وملف تعريف المتصفح على الجهاز؛ نسخ ملفات التطبيق إلى جهاز آخر لا ينسخ IndexedDB. حذف بيانات الموقع أو إعادة ضبط ملف المتصفح قد يحذف السجلات، ويمكن لمستخدم آخر يستخدم ملف المتصفح نفسه الوصول إليها. لا توجد مزامنة أو إرسال تلقائي إلى خادم.

النسخ الاحتياطي الكامل يشمل المشاريع والأهداف والدخل والمصروفات والميزانيات والصناديق والأصول والديون وسجل التدقيق. يمكن استيراد نسخ الإصدار 1 و2 و3؛ يُتحقق من البيانات وتُنشأ نسخة محلية من الحالة الحالية قبل الاستعادة.

يمكن تنزيل نسخة مشفرة باستخدام AES-GCM-256 ومفتاح مشتق بـ PBKDF2-SHA-256. كلمة المرور لا تُحفظ في الملف أو تُرسل إلى خادم؛ احتفظ بها منفصلة، إذ لا يمكن استعادة النسخة المشفرة دونها. يتطلب التشفير سياقًا آمنًا مثل localhost أو HTTPS. الاستعادة تعرض ملخص محتويات الملف وتستبدل البيانات بعد التأكيد؛ لا تدمج النسخ.

## الحسابات والحدود

- المبالغ تحفظ بوحدات العملة الصغرى الصحيحة. لا يجمع التطبيق عملات مختلفة ولا يحوّل بينها؛ يجب أن تطابق عملة صندوق الهدف عملة المشروع قبل التحويل إليه.
- الفائض الشهري = الدخل الفعلي − المصروفات الفعلية − الالتزامات المختارة. يُحتسب المصروف المشترك مرة واحدة في الإجمالي. يوزع فقط في حساب الفائض الفردي عند إدخال نسب الأعضاء، ولا تُطبّع النسب تلقائيًا.
- الرصيد الافتتاحي غير المرتبط بعضو لا يُنسب إلى مساهمات الأعضاء. نسب التوزيع الناقصة تظهر كتسوية غير مكتملة.
- أسعار الذهب يضيفها المستخدم يدويًا. لا يوجد تسعير سوقي مباشر ولا نصيحة استثمارية.
- تكلفة البيع تستخدم توزيعًا تناسبيًا لتكلفة سجل الأصل بين الكمية المباعة والمتبقية. تعديل شراء ذهب مسجل يحدّث حركة النقد ويعيد احتساب المبيعات التابعة. تعديل الذهب اليدوي يعيد احتساب مبيعاته دون إنشاء حركة شراء نقدية.
- السجل لا يحدد الملكية القانونية للأصول. الديون منفصلة عن الدخل والمصروفات. تراجع آخر عملية متاح عندما يحمل أحدث سجل تدقيق معلومات عكس موثقة.

## الاختبارات

شغّل اختبارات المحرك المعزولة من هذا المجلد بالأمر:

```sh
node --test tests/*.test.js
```

الاختبارات تستخدم بيانات اصطناعية، وتشمل عرض الواجهة ومسارات تحرير السجلات. لم أختبر ترحيل قاعدة مستخدم حقيقية أو محاكاة هاتف كاملة؛ يجب إجراء ذلك عند اعتماد إصدار نهائي على الأجهزة المستهدفة.
